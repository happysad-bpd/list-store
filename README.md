# Интернет-магазин издательства «ЛИСТ»

Учебный многостраничный сайт на HTML, CSS и JavaScript. Сервер и база данных для запуска не требуются: данные сохраняются в `localStorage` браузера.

## Запуск

Откройте `index.html` в браузере. Для корректной работы всех переходов можно запустить папку через расширение Live Server в Visual Studio Code.

## Возможности

- CSS-слайдер новостей на главной странице без JavaScript;
- горизонтальное выпадающее меню;
- адаптивный каталог, поиск, фильтрация и сортировка;
- карточка книги и добавление в корзину;
- отдельная страница авторов;
- расширенная регистрация из первой лабораторной, вход и личный кабинет;
- изменение количества товаров и удаление из корзины;
- учебное оформление и оплата заказа;
- история заказов;
- административное добавление, редактирование и удаление книг;
- анимированная страница 404 из лабораторной работы № 5;
- режим для дальтоников с безопасной сине-оранжевой палитрой и графическими узорами;
- адаптация под компьютер, планшет и телефон.

## Последние изменения

- единая закреплённая шапка на всех страницах;
- бургер-меню на экранах шириной до 760 px;
- закреплённые элементы «Оформить заказ» и «Оплатить»;
- увеличенные мобильные кнопки изменения количества и удаления товара;
- более компактные отступы в мобильной корзине.
